# E-Life Advisor Workspace 示範情境

所有案例、商品、價格、門市與員工均為虛構示範資料。資料預設儲存在**店員端目前網域**的 localStorage；按左側「重設示範資料」可回到起始狀態。

## 建議的 3 分鐘流程

1. 在展示入口開啟顧客端連結，說明現有診斷體驗仍由 Netlify 提供；這個原型尚未將兩個前端接到同一資料庫。
2. 回到店員端的「工作總覽」，開啟 `EL-001`。它是兩隻貓、獨處 6–8 小時、已有清淨機、關注空氣品質與居家安全的待確認案件。
3. 在「預約管理」選取 EL-001，按「確認預約」，再按「開始準備」。此操作會更新清單、詳情與操作歷程。
4. 在「顧客需求」勾選／新增待確認問題，使用 AI 面板問「我應先確認什麼？」；回應會明示是規則式示範邏輯。
5. 前往「商品與知識查詢」，挑 1–3 個示範商品比較，然後加入 EL-001 的準備清單。
6. 回到 EL-001，標記準備完成；到「服務紀錄」新增一筆顧問紀錄與待追蹤事項。

## 其他案例

| 案件 | 示範情境 | 初始狀態 |
| --- | --- | --- |
| EL-001 | 兩隻貓、空氣品質／安全、已有清淨機 | 待確認 |
| EL-002 | 狗家庭、地板毛髮、比較掃拖機器人 | 準備中 |
| EL-003 | 新居家庭、預算未定、先了解方案 | 已確認 |
| EL-004 | 狗家庭、操作教學與夜間查看 | 已服務 |
| EL-005 | 貓家庭、外出安全與悶味 | 準備完成 |
| EL-006 | 長者家庭、照明與夜間安全 | 待回覆改期 |
| EL-007 | 狗家庭、暫緩規劃 | 已取消 |
| EL-008 | 新居家庭、清潔與照明整合 | 聯繫未果 |

「提出改期」只會記錄店員建議，絕不代表顧客已同意；「確認預約」也只是在示範資料改變狀態，不是正式門市預約成立。
